Build a polished, production-quality VTU mobile app prototype for Nigeria.

IMPORTANT:
This is a MOBILE APP UI prototype, not a web dashboard.
Focus heavily on the mobile UX, screen structure, navigation, interactions, and visual polish.

Use realistic demo data throughout the app. Do NOT connect to real VTU providers, payment gateways, databases, or APIs yet.

TECH STACK:
- React Native
- Expo
- TypeScript
- Expo Router
- NativeWind/Tailwind for styling
- Use reusable components
- Make the architecture easy to connect to a real backend/API later

APP CONCEPT:
A modern Nigerian VTU app where users can:
- Buy airtime
- Buy data
- Pay electricity bills
- Pay cable TV subscriptions
- Purchase education-related services
- Fund their wallet
- View transactions
- Receive notifications
- Manage their profile
- Use referral features

DESIGN DIRECTION:
Create a clean, modern fintech-style interface.

Visual style:
- White/light background
- Blue as the primary brand color
- Green for successful transactions
- Red for failed transactions
- Subtle gray backgrounds
- Rounded cards
- Modern typography
- Clean spacing
- Professional fintech aesthetic
- Smooth animations where appropriate
- Large touch targets
- Mobile-first design

Do not make it look like a generic template.
The UI should feel like a real Nigerian fintech/VTU application.
